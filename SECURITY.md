# Sicurezza

Non pubblicare vulnerabilità in una issue pubblica. Usa la funzione **Report a vulnerability** nella scheda Security del repository oppure contatta privatamente il maintainer tramite il profilo GitHub.

Indica impatto, passaggi di riproduzione e versione/commit coinvolto. Non includere token, cookie, dati personali o credenziali nei log. Il progetto non richiede segreti per leggere le fonti pubbliche; `GITHUB_TOKEN` è fornito esclusivamente da GitHub Actions con permessi minimi.

Le versioni supportate sono il branch `main` e l'ultima versione pubblicata del feed.
